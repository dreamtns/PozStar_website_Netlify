# PozStar Pilot

Static site for PozStar high-precision surveying.

## Deploy

From the project root, with the [Netlify CLI](https://docs.netlify.com/cli/get-started/) installed and the site linked:

```bash
netlify deploy --prod --dir=.
```

`--dir=.` publishes the current directory. `--prod` deploys it to the production site.
