PPP Service

What is PPP?
• PPP technology is a precise positioning technology that corrects each error using satellite
  orbits and clock messages, then obtains high positioning results through the corrected
  observation data from the GNSS receiver.
• Typically, there are HAS from Galileo and B2b from Beidou.

 It has similar structure to SBAS, but what are the differences?
• SBAS (geostationary satellite) is regional one while PPP (HAS) service provides single
   calibration stream worldwide.

Advantages of PPP serivce
• Compared to existing PPP, it is open and free.
• PPP can be used where environmetns of RTK base station operation is difficult or
  connectionis difficult. It means some of RTK work can be replaced.

What is PPP – HAS?
• It is a service that provides free high-precision position correction (PPP) to worldwide by
  Galileo satellite signals which is controlled by Europe.
• Typically, there are HAS from Galileo and B2b from Beidou.

 How about precision?
• It provides maximum 0.025m vertically and horizontally.
What is PPP – B2b?
• It is a service provides free high-precision position correction (PPP) to Asia-Pacific
  region byBeidou satellite signals which is controlled by China.
• Typically, there are HAS from Galileo and B2b from Beidou.

 How about precision?
• It provides maximum 0.06m horizontally and 0.08m vertically.
